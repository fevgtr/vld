## Submitting code

Programming assignments go to Tsinghua's own online judge:

- Judge: <https://dsa.cs.tsinghua.edu.cn/oj/>
- How to use it: <https://dsa.cs.tsinghua.edu.cn/oj/static/oj-book.html>
- How the assignments are graded: <https://dsa.cs.tsinghua.edu.cn/oj/static/pa-book.html>

Two things that matter:

1. **Register the judge with the same email as the XuetangX account**, or the
   grades don't sync back to the course.
2. The judge compiles with `g++ -std=c++14 -O2`. No headers are included for you,
   and `main` must return `int`. Worth matching locally so nothing surprises me
   on submission.

## Textbook and code

The course follows Prof. Deng's own book, *数据结构（C++语言版）*. Slides, sample
code and errata are all on the book's page:

- <https://dsa.cs.tsinghua.edu.cn/~deng/ds/dsacpp/>

## What the course assumes I already know

- **C++**: classes, inheritance, operator overloading, virtual methods, templates
- **Discrete maths**: sets, induction, series, recursion
- **Probability**: expectation and linearity of expectation

## Options I looked at but didn't take

- [Stanford CS106B](https://cs106b.stanford.edu/): C++, excellent materials, but no way to get work graded.
- [UIUC Accelerated CS Fundamentals](https://www.coursera.org/specializations/cs-fundamentals) (Coursera): also C++, free to audit, but shallower.
- UC San Diego's DSA specialisation: would have needed financial aid, and it mixes Python, Java and C++.
- [USACO Guide](https://usaco.guide/) / [CSES](https://cses.fi/problemset/): problem sets, not a course. Good practice but not something I could follow week to week.
