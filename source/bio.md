**Steven, Grade 12**

I like taking things apart to see how they work, whether that's code or a system I use every day.

## Course

Data Structures (数据结构) by Professor Deng Junhui, Tsinghua University. Free on [XuetangX](https://www.xuetangx.com/). Lectures are in Chinese, code is all C++. I haven't switched courses.

## What I hoped to gain

I finished AP Computer Science A and have some USACO experience, so I'm comfortable with C++ and basic algorithms. But AP CS A stops before real algorithm analysis, and in competitive programming I kept running into data structures I only half understood. I wanted to learn how trees, heaps, hash tables, and graphs work, and how to estimate time complexity on sight.

## A quote

"It is time to unmask the computing community as a Secret Society for the Creation and Preservation of Artificial Complexity." — Edsger Dijkstra

## Advice for a G10 student starting VLD

Pick a course you want to finish, not one that sounds impressive. VLD is self-paced, so nobody is going to remind you to watch the next lecture. If the subject doesn't interest you enough to open it on your own every Friday, you'll fall behind and the journal entries will start feeling made up. Do the assignments before watching the answer videos.
