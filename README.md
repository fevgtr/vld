# VLD — Data Structures & Algorithms in C++

Learning journal for my Virtual Learning Development project at KCIS.
Built with [Hexo](https://hexo.io/) + the [Fluid](https://hexo.fluid-dev.com/) theme.

## Writing a new entry

```bash
hexo new "Week 8: what I did"
```

Edit the file it creates under `source/_posts/`, then preview and publish:

```bash
hexo server        # preview at http://localhost:4000/vld/
hexo clean && hexo deploy   # build and push to GitHub Pages
```

Half-finished entries live in `source/_drafts/` and don't appear on the site.
Run `hexo publish <filename>` to move one into `_posts/`.
